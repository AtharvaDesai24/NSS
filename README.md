# NSS Unit Website (React + Vite)

    npm install
    npm run dev      # http://localhost:5173
    npm run build

Edit `src/config.js` (unit name, Core Committee URL, video, contact) and `src/data/nssData.js`
(years, team, events, albums). Put your hero video at `public/videos/nss-highlight.mp4`.
Replace `src/components/Logo.jsx` content with your official logo image.
